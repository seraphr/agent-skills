## 0. 事前の確認

### 0.1. 利用可能なコマンド・ツールの確認

本スキルで実施するGithubへの操作に使うコマンド・ツールは以下の優先順位で選択してください。

1. ghコマンド
    - 認証済みであることを確認してください。
2. github mcpが提供する、githubの関連ツール
    - PRの情報の取得が利用可能であることを確認してください
    - （案だけでなく）レビューコメントの作成が依頼されている場合は、コメントの追加ツールが利用可能であるか確認してください。

認証済みのghコマンドが利用可能なら、GitHub MCPの設定・確認は不要です。
ghコマンドが利用できない場合はGitHub MCPを確認し、どちらも利用できない場合は停止してユーザに準備を促してください。

## 1. コメント先PRの特定

- 対象PRが指定・特定されている場合はそのPRを対象としてください。
- 指定されていない場合は、現在のブランチから対象PRを特定してください。
- 対象PRが特定できない場合は、ユーザに確認してください。


## 2. コメント案の作成

- 提供された[マニュアル](./references/pr-comment-manual.md)に従い、コメント化対象の個別レビュー指摘から、PRコメントの本文と付与先を作成してください。
- マニュアルに記載の`## 9. 完成前の確認`の各チェックを必ず実施してください。
    - 利用可能であれば、この確認をTODOs(plan tool)の単独のタスクとしてください。
- 対象のPRと指摘の内容が一致しない（リポジトリやPRが誤っている、指摘が古い、既に解決されている等）の場合は、作成を停止してユーザにその旨を伝えてください。

## 3. 生成結果の出力

### 3-1 レビューコメント案の作成を依頼されている時

レビューコメント案の作成を依頼されているときは、上記手順で作成したコメント案を、ユーザに提示してください。
コメント案の本文は、単一のmarkdown形式で提示し、その他の作成用メモは分離して提示してください。


### 3-2 レビューコメントの作成を依頼されている時

レビューコメント作成を依頼されている場合は、上記手順で作成したコメント案を元に、対象のPRに対して実際のレビューコメント（Pending状態）を作成します。

- 既に認証ユーザのPending状態のレビューが存在する場合は、そのレビューにコメントを追加してください。
- 認証ユーザのPending状態のレビューが存在しない場合は、新たにPending状態のレビューを作成してください。
- コメントの本文の作成には、以下の`コメントテンプレート`を使用してください。
- 選んだ形式をPendingで作成できない場合は、本文案と理由をユーザに提示してください。
- レビューはsubmitせず、作成後に所属レビューとPending状態を確認してください。

#### コメントテンプレート

```md
{コメント案の本文}

----

コーディングエージェントによる半自動コメント生成スキルの試用中です。
このコメントはコーディングエージェントによって作成されました。
```
