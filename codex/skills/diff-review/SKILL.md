## このスキルを用いて行うこと

サブエージェントを用いて現在のdiffをレビューし、現在のコードが受け入れ可能かどうかを判定し、必要であれば修正すべき点を網羅的に指摘してください。
あなたはサブエージェントの管理と、最終的なレビュー結果のまとめを担当してください。

レビュー結果はコンソールへの出力として、markdown 形式で出力してください。


## 重要な注意事項

- `レビューの手順` は `plan tool`（TODOs）を用いて実施してください。
    - この手順は非常に長く、あなたが手順の詳細を忘れてしまう可能性があります。
    - 忘れてしまうのを防ぐため、各項目は、要約せず、サブアイテムを含めて全文をTODOに入れてください。

## 作業ディレクトリ

サブエージェントからの報告や個別の調査結果、調査中のメモなどを保存するディレクトリとして`.agent/temp/review/leader`を利用してください。
このディレクトリは、あなたが読み書きして利用するための領域です。 最終的な報告には含まれないため好きなように、長い作業で、サブエージェントからの報告や検証結果を忘れてしまわないよう、外部記録領域として利用してください。

## diffを取得するベースコミット

diffを取得するベースコミットは以下の手順で決定します。

- 比較対象のコミット・ブランチ・タグが指定されている場合は、指定された対象とHEADとのマージベースをベースコミットとします。
    - 例えば、比較対象が `feature-branch` の場合は、`git merge-base feature-branch HEAD` の出力がベースコミットとなります。
    - `リモートトラッキングブランチ`との比較が指定された場合は、現在のブランチに設定された upstream（@{upstream}）を比較対象とし、`git merge-base '@{upstream}' HEAD`の出力をベースコミットとします。
    - ベースコミットの取得に失敗した場合や、`リモートトラッキングブランチ`が比較対象とされたにもかかわらず、upstreamが設定されていない場合は動作を停止し、ユーザにエラーを通知してください。
- 指定がない場合は、`HEAD`をベースコミットとします。

## レビューの手順

0. `.agent/temp/review`が存在する場合は動作を停止し、ユーザに一時ディレクトリの削除を促してください。
    - すでに別のレビューが実施中か、以前のレビューの一時ディレクトリが残っている可能性があります。
1. `mkdir -p .agent/temp/review/leader`を実行し、一時ディレクトリを作成してください。
2. レビュー対象の情報を収集して、ファイルに保存してください。
    1. `<skill root>/scripts/output_diff.sh "$base_commit" .agent/temp/review/target.diff`を実行して、レビュー対象のdiffを取得し、ファイルに保存してください。
        - diffの取得に失敗した場合はレビューを停止し、ユーザーにエラーを通知してください。
    2. GitHubのIssueのURLが指定されている場合、`<skill root>/scripts/show_issue.sh`を実行して、課題の内容を取得し、`.agent/temp/review/issue_info.txt`に保存してください。
3. `<skill root>/references/procedure-manual.md`の内容に従い、サブエージェントによるレビューと結果の統合を行ってください。
    - `<skill root>/references/review-points`ディレクトリには、レビュー観点ごとにファイルが分かれて保存されています
    - `.agent/temp/review/issue_info.txt`が存在しない場合、要件の確認が出来ないため、要件充足性を確認する観点はレビュー対象観点から除外してください
4. 最終的なレビュー結果を markdown 形式で出力してください
5. `rm -rf .agent/temp/review`を実行し、一時ディレクトリを削除してください
    - 削除の際、`.agent/temp/`や`.agent/`は削除しないでください


## Available scripts

スキル配下には、以下のスクリプトが用意されています。

### `<skill root>/scripts/show_issue.sh`

指定された課題の内容を表示するコマンドです。
課題の本文、コメントを全て取得して標準出力に出力します。

実行例:

```bash
<skill root>/scripts/show_issue.sh <issue_url>
```

### `<skill root>/scripts/output_diff.sh`

現在のワークスペースのdiffを取得して指定されたファイルに出力するコマンドです。
ベースコミットから現在の作業ツリーまでの差分を取得し、コミット済み変更・未コミット変更・無視されていない未追跡ファイルを含みます。

実行例:

```bash
<skill root>/scripts/output_diff.sh <target-commit> <output-path>
```
