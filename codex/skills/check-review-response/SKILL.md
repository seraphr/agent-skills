# 手順

## 1. 確認対象コメント一覧を決定する

1. GithubのPRのレビューもしくは個別のレビューコメントに対するURLが指定されているかを確認する
2. URLの指定がされていない場合は、ユーザにURLの指定を依頼する
3. 指定されたURLが、レビュー・コメントに対するものでない場合は、その旨を報告して停止する
4. レビューのURLが指定されている場合はそのレビューに所属するコメントをすべて確認対象とし、個別のレビューコメントのURLが指定されいる場合はそのコメントのみを確認対象とする

## 2. 確認対象コメントの対応状況を調査する

確認対象コメントそれぞれについて、問題が解決しているか、コーナーケースなどが残っていないか調査・検討・検証し、結果をレポートする。
